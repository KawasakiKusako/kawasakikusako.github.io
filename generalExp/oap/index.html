Pipeline Architecture

A deterministic state
machine. No black boxes.

How it works
Each stage spawns a Claude Code CLI headless call. The stage prompt is assembled from the skill definition, research topic, and prior artifacts. The model writes outputs to a staging directory — the platform reads them back, hashes content, and versions them in the artifact ledger. Checkpoints between stages let you confirm results before proceeding. Integrity failures auto-retry.
STAGE 01
Research
Deep research with methodology blueprint, RQ brief, and devil's advocate review.
STAGE 02
Write
Full paper draft generation from research synthesis and annotated bibliography.
STAGE 03
Integrity Check
Automated DOI verification via Crossref. Failed citations trigger retry loop ≤3 rounds.
STAGE 04
Peer Review
Simulated review with configurable reviewer count, difficulty, and editorial standards. Structured report output.
STAGE 05
Revise
Revision based on reviewer feedback with response letter and revision roadmap.
STAGE 06–07
Re-Review & Re-Revise
Second review loop. Capped at 2 revision rounds total.
STAGE 08
Final Integrity
Final citation and completeness check before finalization.
STAGE 09
Finalize
Materialize final paper. Pandoc/tectonic for DOCX/PDF output when available.
STAGE 10
Process Summary
Executive summary of the entire pipeline run — tokens, costs, decisions, artifacts.
Core Features

Built for researchers,
not for engineers.

Checkpoint System

Stage confirmation gates. Mandatory checkpoints cannot be skipped. Integrity failures auto-retry up to 3 rounds.

Artifact Ledger

13 schemas × SHA-256 hashing × Material Passport. Downstream artifacts auto-flagged STALE on upstream edits.

Model Routing

Agent > mode > stage > default. Passes --model and --effort directly to Claude Code CLI. Switch providers anytime.

SSE Real-time Logs

6 event types streamed live. 15-second heartbeat. Full replay on reconnect. Color-coded log viewer.

Budget Transparency

Token and cost estimates at creation. Real-time actual vs. estimated. Hard cap protection.

Data Interop

Workflows mount sandbox data sources. Stage execution auto-injects sandbox file context. VSCode file sync.

Custom Prompts

Four independent system prompt slots: sandbox, project chat, research stage, and writing stage.

Python Env Detection

Auto-scans PATH, conda environments, and common installs. One-click selection for code execution.

Get Started

Three commands.
That's it.

Prerequisites: Python 3.11+ · Node.js 18+ · Claude Code CLI (npm i -g @anthropic-ai/claude-code)

# 1) Install Python dependencies
pip install -r backend/requirements.txt

# 2) Install frontend dependencies
cd frontend && npm install

# 3) Start both servers
cd backend && PYTHONUTF8=1 python -m uvicorn app.main:app --port 8000
cd frontend && npm run dev

# Open → http://localhost:5173

Windows: prepend PYTHONUTF8=1 to all Python commands.
